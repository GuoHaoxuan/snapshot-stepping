# SVOM/GRM 闪电证实 TGF 样本的科学表征（2026-09-07）

v6 目录里 fa ≤ 1e-5、落在 WWLLN 覆盖内、且关联到闪电的 **82 个 TGF**（偶然关联期望合计 0.32，
即样本几乎不含误关联）。

## 文件

- `svom_tgf_timing_spectrum.png` —— (a) 叠加光变、(b) T50/T90 分布、(c) 叠加计数谱、(d) 计数与死时间。
- `svom_tgf_geography.png` —— (a) 位置（按 T90 着色）、(b) 地方时、(c) 纬度（含轨道曝光期望）。
- `svom_tgf_per_tgf.csv` —— 逐个 TGF 的 T50/T90（含自举误差）、计数、死时间修正后的计数、
  本底率、地方时、单高斯拟合的 KS p 值。

## 怎么算的

事例来自 L1B（集群 `scripts/cluster/svom_tgf_sample.py` 导出每个 TGF 中心 ±50 ms 的逐事例，
以及 ±1 s 的本底谱），离线分析与画图是 `scripts/plot_svom_tgf_sample.py`。

- **事例准入**：`EVT_TYPE==0`、`25 ≤ PI < 256`（v6 能阈 ch25 ≈ 42 keV）、`ANTI_COIN==0`。
  ANTI_COIN==1 是星上标定源（49–57 keV 的线），核心窗与本底窗一律排除。
- **本底**：事例表里 10–50 ms 的环，与核心窗同一份数据、同一套筛选。与 ±1 s 窗互校：
  窗也筛 AC=0 时比值 1.001，不筛时 0.988——差的 1.4% 正是标定源，互相印证。
- **时长**：对 ±5 ms 内的到达时间做非分箱扩展极大似然拟合（已知本底率 + 高斯脉冲），
  T50 = 1.349σ、T90 = 3.290σ，误差用自举。**不能用累积光变的 5%/95% 交点**：±5 ms 窗里
  本底期望 30 余个而净计数中位只有 16 个，交点会被本底涨落推到窗边，T90 会系统性偏大到毫秒量级。
- **能谱**：核心窗取 µ ± 2σ；叠加后用逐能道的泊松（Cash）似然拟合，模型在每道上积分。
  **不分组**——高能段计数少，并出来的能段很宽，用几何中心当能量会把指数带偏 0.2 以上，
  且分组边界会随净谱的微小变化跳动。

## 结论要点

- T50 中位 59 µs（16–84% 37–104），T90 中位 145 µs（91–254），与 TGF 文献的几十到几百微秒相符。
- 叠加计数谱在 8 MeV 以内看不到截断；低增益段（640–8041 keV）单幂律 dN/dE ∝ E^(−0.90 ± 0.07)，
  χ²/dof = 1.06。高增益段（42–640 keV）指数 −1.01 ± 0.04 但 χ²/dof = 2.68，
  300–640 keV 明显下凹，落在两档增益的交界（PI≈110），是响应结构不是物理。
- **要给光子谱必须解卷积**：CALDB 在 `/gecamfs/SVOM/soft/CALDB`，`data/svom/grm/bcf/mc_rsp`
  下有 771 个入射方向、每方向 3 个探头的标准 OGIP 响应（300 入射能 × 4096 道）。
  用它还需要先由姿态四元数定出天底方向在仪器系里的 (θ, φ)，四元数约定尚未核实。
- **流强没给**：同上，缺有效面积。本目录只报计数。
- 死时间不可忽略：`DEAD_TIME` 是逐事例的微秒数（表头 `EVT_DEAD = 4.0 µs`，暴发期间中位 4.17、
  均值 5.34，有堆积迹象）。暴发窗内最忙一路的死时间占比中位 23%，逐探头非瘫痪修正后计数
  ×1.25（中位）。对探测没有影响（判据只看计数超出），对流强与能谱必须修正。
